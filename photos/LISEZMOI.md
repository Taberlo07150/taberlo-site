# Photos du site

Deux dossiers :

- **accueil/** : les photos qui défilent en haut de la page (4 à 6 conseillées, format paysage).
- **galerie/** : les photos de la section « En images » (12 max).

Règles communes (JPEG, 2000 px de large max, 300–500 Ko) :

- Elles s'affichent dans l'ordre des noms : 01-terrasse.jpg, 02-tapas.jpg…
- Le nom sert de description : "03-planche-mixte.jpg" → "planche mixte".
- Si **accueil/** est vide, l'accueil reprend les premières photos de la galerie.
- Si **galerie/** est vide, le site utilise les photos posées directement dans photos/ (ancienne organisation), puis le dossier Drive.

Pour retirer une photo : ouvrez-la sur GitHub › icône corbeille › Commit.
